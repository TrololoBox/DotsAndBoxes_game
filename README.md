# 🎯 Точки и Квадраты — Telegram Bot

Классическая игра "Точки и Квадраты" (Dots and Boxes) в виде Telegram бота.

## ✨ Возможности

- **PvE режим**: Играй против бота трёх уровней сложности (Лёгкий, Средний, Сложный)
- **PvP мировой матчмейкинг**: Найди случайного соперника
- **PvP с другом**: Пригласи друга по ссылке
- **Визуальный рендер**: Красивые изображения игрового поля
- **3 цветовые темы**: Классика, Лес, Ночь
- **Таймеры ходов**: 60 сек (PvE) / 45 сек (PvP)
- **Русский интерфейс**: Тёплые и дружелюбные сообщения

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка

Создай файл `.env`:

```bash
cp .env.example .env
```

Укажи токен бота в `.env`:

```
BOT_TOKEN=your_telegram_bot_token_here
```

### 3. Запуск

```bash
python -m bot.main
```

## 🎮 Правила игры

1. Поле — сетка точек (3×3, 4×4 или 5×5 квадратов)
2. Игроки по очереди ставят линии между соседними точками
3. Если линия завершает квадрат — игрок захватывает его и ходит ещё раз
4. Побеждает тот, кто захватил больше квадратов

## 🛠️ Технологии

- Python 3.10+
- python-telegram-bot 20+
- Pillow (рендеринг изображений)
- In-memory хранилище (без базы данных)
