# TZ: Main Menu

## Goal
Specify the main menu structure and navigation.

## Inputs
- Required menu items.

## Outputs
- Menu layout and button labels.

## Internal logic
- Menu always accessible via /start or back buttons.

## Definition of Done (DoD)
- Main menu contains Play, Profile, Settings, Support Project.

## Negative cases
- Missing required entry.

## Edge cases
- User mid-game hitting /start.

---

## Menu Layout
- Row 1: Play
- Row 2: Profile | Settings
- Row 3: Support Project
