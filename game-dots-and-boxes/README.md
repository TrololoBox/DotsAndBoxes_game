# Dots and Boxes (Telegram Bot) — Architecture Pack

This folder contains the full architecture and technical specifications (TZ) for the Telegram bot-only Dots and Boxes game. It is intended for implementation teams to start building immediately without additional product decisions.

## Contents
- `0_product`: vision, rules, UX principles, open questions.
- `1_design`: player and opponent presentation, rendering, accessibility.
- `2_game_logic`: room lifecycle, turns, captures, scoring, timers.
- `3_modes`: PvE bot design, PvP world matchmaking, PvP friend invites.
- `4_telegram`: bot flow, inline keyboards, callbacks, menus.
- `5_state`: runtime state, cleanup, logging.
- `6_monetization`: support project and cosmetics design.
- `7_analytics`: event metrics.
